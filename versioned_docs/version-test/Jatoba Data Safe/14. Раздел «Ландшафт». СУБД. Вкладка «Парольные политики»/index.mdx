---
title: 14. Раздел «Ландшафт». СУБД. Вкладка «Парольные политики» (Password policies)
---

Раздел «Парольные политики» предназначен для автоматизации и упрощения
работы с парольными политиками и блокировками пользователей целевой
СУБД.

Раздел включает в себя подразделы:

  - Управление политиками (Policy management) (п. 14.1);

  - Привязка ролей (Role Binding) (п. 14.2);

  - Работа с блокировками (п. 14.3).

Корректная работа раздела обеспечивается установленными и настроенными
на целевой СУБД компонент:

  - SecurityProfile, описанного в документе «Руководство
    администратора»;

  - ja\_CSum, описанного в документе «Руководство по настройке. Часть
    14. Контроль целостности. Компонент «ja\_CSum».

Функциональные возможности подраздела доступны на уровне целевой СУБД в
разделе «Ландшафт».
