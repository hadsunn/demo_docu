### 8.14.7. Тип jsonpath [#](https://www.postgresql.org/docs/16/datatype-json.html#DATATYPE-JSONPATH)

Тип `jsonpath` реализует поддержку языка путей SQL/JSON в PostgreSQL, обеспечивая эффективный доступ к данным в формате JSON. Он используется как двоичное представление разобранного выражения пути SQL/JSON, которое определяет, какие элементы должны быть извлечены из данных JSON для дальнейшей обработки в функциях SQL/JSON.

Семантика предикатов и операторов путей SQL/JSON в целом соответствует стандарту SQL. В то же время, для более естественной работы с данными в формате JSON в синтаксисе путей SQL/JSON используются некоторые соглашения из JavaScript:

- Для доступа к свойствам объекта используется оператор точки (`.`).
- Для доступа к элементам массива используются квадратные скобки (`[]`).
- Индексация в массивах SQL/JSON начинается с нуля, в отличие от стандартных массивов SQL, в которых индексация начинается с единицы.

Числовые литералы в выражениях путей SQL/JSON следуют правилам JavaScript, которые в некоторых деталях отличаются от синтаксиса SQL и JSON. Например, в путях SQL/JSON допускаются формы `.1` и `1.`, которые считаются недопустимыми в JSON. Поддерживаются недесятичные числовые литералы и разделители подчеркивания, например, `1_000_000`, `0x1EEE_FFFF`, `0o273`, `0b100101`. При этом (как в JavaScript, но не в стандартном SQL) в путях SQL/JSON недопустимы разделители подчеркивания непосредственно после префикса системы счисления.

В SQL-запросе выражение пути SQL/JSON обычно указывается в виде символьного литерала SQL и должно заключаться в одинарные кавычки, которые в таком значении необходимо экранировать путем удваивания (см. [Раздел 4.1.2.1](https://www.postgresql.org/docs/16/sql-syntax-lexical.html#SQL-SYNTAX-STRINGS)). В некоторых выражениях путей строковые литералы обязательны. На такие встроенные строковые литералы распространяются соглашения JavaScript/ECMAScript: они должны быть заключены в двойные кавычки, а для записи специальных символов в них могут использоваться управляющие последовательности с обратной косой чертой. В частности, двойная кавычка записывается как `\"`, а сама обратная косая черта как `\\`. Прочие управляющие последовательности с обратной косой чертой включают используемые в строках JavaScript `\b`, `\f`, `\n`, `\r`, `\t`, `\v` для представления различных управляющих символов ASCII, `\xNN` для представления кода символа из двух шестнадцатеричных цифр, `\uNNNN` для представления кода символа Unicode в виде четырех шестнадцатеричных цифр и `\u{N...}` для представления кода символа Unicode в виде 1 - 6 шестнадцатеричных цифр.
