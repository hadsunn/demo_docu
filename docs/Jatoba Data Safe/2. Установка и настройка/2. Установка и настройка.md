# Установка и настройка

Установка компонента «Jatoba Data Safe» полностью описана в документе
«Руководство по установке» в одноименном разделе.

Установка компонента происходит в два этапа:

1)  создание служебной БД на базе СУБД (БД) «Jatoba»;

2)  установка компонента JDS (см. документ «Руководстве по установке»).

:::warning[Предупреждение]
СУБД «Jatoba» должна быть установлена в первую очередь.</p>
<p>Для служебной БД JDS обязательно должен быть установлен параметр:
```console
standard_conforming_strings=on
```
Параметр устанавливается автоматически при установке.
:::

Служебная БД будет хранить будет хранить учетные записи пользователей,
технические учетные записи и обеспечивать меры безопасности.

  - «Защищенная система управления базами данных «Jatoba». Руководство
    по установке. 643.72410666.00067-08 95 01»;

  - «Защищенная система управления базами данных «Jatoba». Руководство
