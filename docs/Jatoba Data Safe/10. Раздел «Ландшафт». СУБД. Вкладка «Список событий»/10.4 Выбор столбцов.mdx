---
title: 10.4 Выбор столбцов (Columns)
---

Пиктограмма «Столбцы» (Columns) расположена в правом верхнем углу окна.

При нажатии на нее раскроется меню со списком столбцов, приведенных в
таблице Таблица 10.2.

Таблица 10.2 – Список
столбцов

| **Наименование (RU)**                                   | **Наименование (ENG)**                                       | **По умолчанию** |
| ------------------------------------------------------- | ------------------------------------------------------------ | ---------------- |
| Идентификатор события                                   | **ID**                                                       | Х                |
| Агент                                                   | **Agent**                                                    | Х                |
| Задача                                                  | **Task**                                                     | Х                |
| Файл                                                    | **File**                                                     | Х                |
| Категория события                                       | **Category**                                                 | Х                |
| Дата события                                            | **Event data**                                               | Х                |
| Важность                                                | **Severity**                                                 | Х                |
| Подключение от                                          | **Connection from**                                          | Х                |
| Сообщение                                               | **Message**                                                  | Х                |
| Подробности                                             | **Detail**                                                   | Х                |
| Имя пользователя                                        | **User name**                                                | Х                |
| Имя базы данных                                         | **Database name**                                            | Х                |
| Время вставки в лог                                     | **LOG insertion time**                                       |                  |
| Идентификатор процесса                                  | **Process ID**                                               |                  |

:::note Дополнительная информация
Соответствие событий СУБД категориям мер защиты приказов ФСТЭК России приведено в Приложении к документу «Реализация функций безопасности»
:::

Выбор столбцов осуществляется установкой флажков.

При использовании расширения «pgAudit» в столбец «Message» включаются
дополнительные столбцы, представленные в таблице Таблица 10.3.

Таблица 10.3 – Структура столбца «Error
message»

|                                    | **Expression No.**                       | № выражения                        |
|                                    | **Subexpression No.**                    | № подвыражения                     |
