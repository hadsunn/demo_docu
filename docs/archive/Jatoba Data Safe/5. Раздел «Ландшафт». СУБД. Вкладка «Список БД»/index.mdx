---
title: 5. Раздел «Ландшафт». СУБД. Вкладка «Список БД»
---

Вкладка «Список БД» предназначена для просмотра основных данных БД
текущей СУБД.

Переход во вкладку доступен по пути:

  - Раздел Ландшафт → СУБД → Дерево инфраструктуры → Хост → СУБД →
    Вкладка «Список БД».

При переходе не обязательно точно наводить курсор на объект.

<img src={require('/docs/assets/images/jds-gfm/image32.png').default} alt="Описание" />
Рисунок 5.1 - Вкладка «Список БД»

Во вкладке отображается список БД и основные данные о них:

  - Название БД;

  - Владелец;

  - Размер;

  - Табличное пространство;

  - Кодировка;

  - Текущие сессии.

Поля «Название БД» и «Активность БД» оснащены гиперссылками.

Переход по гиперссылке поля «Название БД» откроет вкладку «Обзор» и
сделает доступным переход к вкладкам:

  - «Расширения» (р. 16);

  - «Анализ рисков» (р. 18);

  - «Матрица доступа» (р. 17).

Переход по гиперссылке поля «Текущие сессии» откроет вкладку «Активность
БД» – «Сессии» (п.п.
12.1).
