---
title: 3.1. Навигация в разделе Ландшафт
---

Навигация в разделе организована по принципу «хлебные крошки»
(breadcrumbs).

В виде иерархической цепочки от имени раздела до уровня сущности СУБД, с
возможностью перехода по уровням иерархии и выбора сущностей СУБД.

Переходы снабжены подсказками.

Раздел «СУБД» имеет две вкладки:

  - «Список СУБД»;

  - «Дерево инфраструктуры».

При переходе пользователя на очередную страницу, если приложение не
может отобразить страницу, то отображается страница ошибки 404.

### Список СУБД

Во вкладке «Список СУБД» выводится список подключенных к JDS СУБД.

В списке отображается пиктограмма с значениями состояния СУБД
аналогичными состоянию в карточке СУБД/Обзор (см. р. 4 Раздел
«Ландшафт». СУБД. Вкладка «Обзор»):

  - Зеленый цвет – «Работает»;

  - Желтый цвет – «Остановлена»;

  - Красный цвет – «Неизвестно».

В период загрузки данных о состоянии СУБД пиктограмма бесцветная.

Время последнего обновления вначале показывает время загрузки списка
СУБД, а после загрузки состояния СУБД:

  - для недоступной СУБД - время обновляется на время
    получения результата неуспешной попытки
    подключения к СУБД;

  - для СУБД, для которой успешно выполнилась команда systemctl status -
    время изменения статуса на текущий статус, которое
    возвращает systemctl.

По умолчанию, автоматическое обновление состояния СУБД во вкладе
выключено. Обновление состояния СУБД доступно в ручном режиме
через кнопку «Обновить» и в автоматическом. Периоды автоматического
обновления составляют 30 сек, 1мин и 5мин.

Переход по гиперссылке СУБД выведет во вкладку «Обзор» и меню доступных
действий, таких как:

  - Назначение ролей;

  - Параметры СУБД;

  - Правила доступа;

  - Доступные расширения;

  - Настройка для ProBackup;

  - Роли СУБД;

  - Проблемы и решения;

  - Активность БД;

  - LDAP синхронизация;

  - Парольные политики.

Отражаемый в верхней строке путь, позволяет перемещаться по разделу, в
строке с именем СУБД из выпадающего списка выбрать подключенную СУБД и
перейти к ней.

### Дерево инфраструктуры

Во вкладке «Дерево инфраструктуры» отображается иерархическая,
древовидная структура хостов, СУБД и БД. В данной
инфраструктуре доступны основные операции такие как:

  - Добавление СУБД;

  - Редактирование параметров СУБД;

  - Обновление содержания вкладки.

В левой части окна дублируются основные меню.

Во вкладке «Дерево инфраструктуры» возможно перейти до уровня БД на
котором доступны

  - Вкладка «Обзор» БД;

  - Меню «Расширения»;

  - Матрица доступа;

  - Анализ рисков.
