Переход в режим сканирования выполняется при нажатии на гиперссылку в
имени правила сканирования в одноименной вкладке.

<img src={require("/docs/assets/images/jds-gfm/image73.png").default} alt="Описание" />

Рисунок 11.3 – Вкладка «Результаты сканирования»

Сканирование возможно:

  - По всем проблемам через пиктограмму «Запустить сканирование»
    находящейся в правом верхнем углу окна;

  - Выборочное сканирование через одноименную пиктограмму в строке
    проблемы.

В случае если сканирование проводилось ранее, то просмотреть результаты
возможно через нажатие на гиперссылку в имени проблемы.

Перейдя по гиперссылке в имени проблемы отобразится их перечень, в
котором доступен поиск по любым значениям.

При сканировании объектов компонент определяет возможные варианты
исправления. В результате, компонент предоставляет
предопределённый, оптимальный вариант решения и
предоставляет выбор решения проблемы пользователю.

Варианты решения проблем представлены на схеме Рисунок 11.5.

Рисунок 11.5 – Схема возможных вариантов исправления

Каждая из найденных проблем лечится индивидуально, т.к. требует
квалифицированного подхода. Для этого необходимо нажать на
строке проблемы. Тем самым вызвать окно «Исправление проблемы».

В открывшимся окне доступен:

  - выбор параметров исправления;

  - просмотр SQL-команды исправления;

  - выбор временного диапазона выполнения задачи;

  - указание комментария.

При установленном флаге «Выполнить сейчас» задача исправления выполнится
немедленно.

Снятый флаг активирует установку даты и времени выполнения исправления в
календаре.
