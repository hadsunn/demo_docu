This chapter describes the installation of PostgreSQL using the source code distribution. If you are installing a pre-packaged distribution, such as an RPM or Debian package, ignore this chapter and see [Chapter 16](</III. Server Administration/install-binaries.md>) instead.

If you are building PostgreSQL for Microsoft Windows, read this chapter if you intend to build with MinGW or Cygwin; but if you intend to build with Microsoft's Visual C++, see [Chapter 18](</III. Server Administration/18. Installation from Source Code on Windows/18. Installation from Source Code on Windows.md>) instead.
