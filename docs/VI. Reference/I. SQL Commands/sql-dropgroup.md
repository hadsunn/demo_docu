## Synopsis
    
    
    DROP GROUP [ IF EXISTS ] _name_ [, ...]
    

## Description

`DROP GROUP` is now an alias for [`DROP ROLE`](</VI. Reference/I. SQL Commands/sql-droprole.md>).

## Compatibility

There is no `DROP GROUP` statement in the SQL standard.
