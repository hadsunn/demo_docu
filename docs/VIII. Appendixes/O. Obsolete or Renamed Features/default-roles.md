PostgreSQL 13 and below used the term “Default Roles”. However, as these roles are not able to actually be changed and are installed as part of the system at initialization time, the more appropriate term to use is “Predefined Roles”. See [Section 22.5](</III. Server Administration/22. Database Roles/predefined-roles.md>) for details on this change.
