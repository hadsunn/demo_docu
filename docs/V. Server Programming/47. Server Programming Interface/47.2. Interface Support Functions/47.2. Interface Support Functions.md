[SPI_fname](</V. Server Programming/47. Server Programming Interface/47.2. Interface Support Functions/spi-spi-fname.md>) — determine the column name for the specified column number
[SPI_fnumber](</V. Server Programming/47. Server Programming Interface/47.2. Interface Support Functions/spi-spi-fnumber.md>) — determine the column number for the specified column name
[SPI_getvalue](</V. Server Programming/47. Server Programming Interface/47.2. Interface Support Functions/spi-spi-getvalue.md>) — return the string value of the specified column
[SPI_getbinval](</V. Server Programming/47. Server Programming Interface/47.2. Interface Support Functions/spi-spi-getbinval.md>) — return the binary value of the specified column
[SPI_gettype](</V. Server Programming/47. Server Programming Interface/47.2. Interface Support Functions/spi-spi-gettype.md>) — return the data type name of the specified column
[SPI_gettypeid](</V. Server Programming/47. Server Programming Interface/47.2. Interface Support Functions/spi-spi-gettypeid.md>) — return the data type OID of the specified column
[SPI_getrelname](</V. Server Programming/47. Server Programming Interface/47.2. Interface Support Functions/spi-spi-getrelname.md>) — return the name of the specified relation
[SPI_getnspname](</V. Server Programming/47. Server Programming Interface/47.2. Interface Support Functions/spi-spi-getnspname.md>) — return the namespace of the specified relation
[SPI_result_code_string](</V. Server Programming/47. Server Programming Interface/47.2. Interface Support Functions/spi-spi-result-code-string.md>) — return error code as string

The functions described here provide an interface for extracting information from result sets returned by `SPI_execute` and other SPI functions.

All functions described in this section can be used by both connected and unconnected C functions.
