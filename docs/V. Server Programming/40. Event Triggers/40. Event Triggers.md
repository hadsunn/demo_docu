To supplement the trigger mechanism discussed in [Chapter 39](</V. Server Programming/39. Triggers/39. Triggers.md>), PostgreSQL also provides event triggers. Unlike regular triggers, which are attached to a single table and capture only DML events, event triggers are global to a particular database and are capable of capturing DDL events.

Like regular triggers, event triggers can be written in any procedural language that includes event trigger support, or in C, but not in plain SQL.
